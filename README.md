# PowerMeterAtom - ESP32 Electrical Telemetry & Power Meter

---

### 🌐 English

Embedded hardware device measuring electrical voltage, current, and energy consumption, transmitting real-time telemetry to cloud dashboards.

#### Key Features:
* High-accuracy sensor sampling
* WiFi/MQTT telemetry streaming
* Low-power hardware architecture

* **Tech Stack**: `C++` `ESP32` `MQTT` `Hardware Integration`

---

### 🌐 Español

Dispositivo hardware embebido para medición de voltaje, corriente y consumo eléctrico, transmitiendo telemetría en tiempo real a dashboards cloud.

* **Tecnologías**: `C++` `ESP32` `MQTT` `Hardware Integration`
